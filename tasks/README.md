# 历史任务素材

`pytorch/` 保留旧版本任务的题面、源码来源、参考补丁和测试补丁，供 v0.9 重制与审查。
这里的 `task.json` 使用旧 schema，不能直接交给 v0.8 CLI；历史 `verified` 等标签
也不表示已通过新一轮数据准入。逐题范围和质量问题见[历史任务初审](../docs/v0.8/task_disposition.md)。

当前可执行的上游任务入口是[迁移候选](../datasets/v0.8_candidates/README.md)。
新任务格式见[任务指南](../docs/v0.8/task_format.md)。

原任务素材继续保留，不恢复旧运行器或环境注册表。需要对应版本的代码、环境和实验
上下文时，从[版本历史](../docs/history/README.md)查阅原始文档与提交。
