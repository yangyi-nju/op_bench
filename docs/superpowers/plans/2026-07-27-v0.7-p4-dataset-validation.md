# OpBench v0.7 P4 Dataset Freeze and Validation Cohort Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Subagent execution is disabled for this repository session.

**Goal:** Freeze rebuildable 25-task cumulative, 6-task Boundary, and 8-task Precision Datasets, then complete an integrity-verified 18-attempt real Codex Validation Cohort over the six new Boundary Tasks.

**Architecture:** Keep P1 Dataset Freeze v1 scoped to the six Factory-created Boundary Tasks, and add a separate content-addressed Release Composition contract for inherited and restored tasks. Make v1 registered tests load the current authoritative source before selectors, add five exact historical Runtime Profiles, generalize the MCP report contract to any non-empty cohort partition, and publish only deterministic redacted validation artifacts.

**Tech Stack:** Python 3.11/3.12, unittest, dataclasses, canonical JSON/SHA-256, Draft 2020-12 JSON Schema, Docker/RemoteDocker, official PyTorch wheels, exact PyTorch source snapshots, Codex MCP Adapter, existing OpBench v0.6 Runtime/Evaluation/Integrity contracts, v0.7 Factory contracts.

## Global Constraints

- Do not change P1 Dataset Freeze v1 semantics or synthesize Factory provenance for inherited tasks.
- Do not lower Admission gates, alter Hidden Tests, or change Gold Patches in response to Agent results.
- Every verified Dataset entry must bind current Task/Admission replay identity and Registry assets.
- Agent source preparation never substitutes for fresh evaluator source preparation.
- Validation uses one model and is not a leaderboard or feedback-causality experiment.
- Private target configuration, host identity, credentials, absolute user paths, raw Agent text, and unbounded logs never enter committed artifacts.
- Transient provider, SSH, container, MCP, or evaluator failures are infrastructure-invalid retries, not logical Agent failures.
- Existing v0.6 4-cohort/51-Attempt report behavior remains compatible.
- Generated output is append-only or exact-byte idempotent; mismatching pre-existing output fails closed.
