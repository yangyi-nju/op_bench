# OpBench v0.7 P1 Factory Contract Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the local, deterministic v0.7 Dataset Factory contract, Boundary screening, lifecycle, and synthetic Freeze workflow without live network or runtime execution.

**Architecture:** Add a separate `op_bench.factory` package whose immutable contracts reference the existing builder, Admission, Dataset, and v0.6 Runtime artifacts rather than replacing them. Factory artifacts use v0.6 canonical JSON identities, structured screening findings, evidence-gated lifecycle snapshots, and a deterministic Dataset Freeze projection.

**Tech Stack:** Python 3 standard library, immutable dataclasses, JSON Schema draft 2020-12 documents, `unittest`, existing OpBench canonical/hash and validation helpers.

## Global Constraints

- Do not query GitHub, the PyTorch mirror, or any other network service in P1.
- Do not run Agent, Docker, SSH, CUDA, source build, or real Admission workloads.
- Do not publish `datasets/pytorch_v0.7`.
- Do not change v0.6 Action, Runtime, Evaluation, Scoring, or Trace semantics.
- Preserve all v0.5 and v0.6 Task, Dataset, Admission, and run artifacts.
- Add no third-party Python dependency.
- Use canonical JSON and SHA-256 for every Factory identity.
- New Task taxonomy fields are optional for historical tasks and strict when present.
- Each implementation task follows red-green-refactor and ends with a focused commit.
