# v0.8 执行计划

范围修订于 2026-09-14，完成状态复核于 2026-09-23。本轮落实[当前设计](design.md)：固定 MCP 框架比较模型，
保留独立评估，主指标收敛为 `resolved_rate`。实施与验证已完成；历史原生 Agent
验证不作为新循环的验收证据。逐项结果只维护在[验收矩阵](acceptance_matrix.md)。

| 顺序 | 工作 | 完成时应能观察到的行为 |
| --- | --- | --- |
| 1 | 收敛设计、版本范围和文档 | v0.8 工程、v0.9 数据和准入、v0.10 多模型实验各有明确范围，旧远期条件不再阻塞本轮 |
| 2 | 核对旧实现中的关键行为 | 工具权限、公开与私有评分、补丁捕获、实际构建加载、超时和恢复采用一致口径 |
| 3 | 实现固定模型循环与 MCP 工具 | 更换模型只改变模型配置或协议适配；工具语义和主循环相同；任务代码在隔离工作区执行 |
| 4 | 简化报告与运行配置 | 预先计划模型 × 任务，每题一次；输出一个 resolved_rate 及必要状态，准入标签不阻止开发集统计 |
| 5 | 删除退役路径及其专用资产 | 不再有任意 Agent argv、模型网关/relay、复杂比较和重复择优统计；保留有用评分能力 |
| 6 | 回归和最小真实模型联调 | 成功与错误补丁、超时冻结、中断恢复、独立评分、报告重算和安装路径可用；优先以本地 Codex 的 gpt-5.5 做小任务联调 |

本地 Codex 联调由控制器调用模型，只允许模型通过相同 MCP 工具协议提出动作。
实际模型选择与失败均记录；不能因为配置名字包含某个模型就宣称实际调用成功。
9 月 14 日的真实模型记录保留原协议，后续重构由工程回归与脚本化联调验证。
本次只验证接入与编排；v0.10 开始前仍需对目标服务逐个做真实 API 小样本联调。

最终结果见[状态](development_status.md)和[验证报告](validation_report.md)。
数据素材及历史原始结果保留其原协议，v0.9 再完成分类配额与流程化准入。
