# v0.8 工程验收

范围修订于 2026-09-14，工程简化复核于 2026-09-22，文档复核于 2026-09-23，按[当前设计](design.md)收敛。此前 V01—V21 混合了自主 Agent、
正式准入和研究发布要求，不再作为本轮完成清单。历史结果保留原协议，不能直接
将旧运行标记为固定 MCP 模型框架的通过证据。

## 本轮必要验收

| 项目 | 必要行为 | 本轮状态 |
| --- | --- | --- |
| E01 模块分工 | 数据不执行模型；固定循环通过模型接口和 MCP 工具工作；评估不依赖求解器；报告只读计划和结果 | 通过：模块审查、独立评估与固定循环回归 |
| E02 固定工具与隔离 | 所有模型获得同样的工具；路径被限制在工作区；构建和公开测试在无网络、无私有 grader/凭据的 Docker 会话内执行 | 通过：当前真实 Docker 工具测试、越界访问回归；另有 9 月 14 日 GPT-5.5 controlled 联调记录 |
| E03 输入和补丁 | 源码没有上游历史与 remote；新增、修改、删除和合法构建修改可进入冻结补丁；控制元数据和运行产物不进入源码提交 | 通过：工作区历史、忽略文件、生成产物及完整框架规模捕获/回放测试 |
| E04 真实构建和独立评分 | 基线及候选构建不访问 grader；候选修改进入实际加载产物；全部必需条件通过才 resolved；空套件、skip、缺失与评分错误不通过 | 通过：真实 Docker、编译加载、数值与变体回归；干净安装四组控制及 verify |
| E05 预算、异常和恢复 | 固定求解预算；截止停止工具执行并冻结；保存模型/工具/环境错误；恢复已结束尝试不重复调用模型；重评保留原补丁及来源 | 通过：超时/服务错误/中断/重评测试；真实模型 resume 无新增请求 |
| E06 统一计分 | 每模型每题一次；resolved / planned；缺失和错误保留分母，报告完整性明确；准入 metadata 不阻止开发统计；报告不写原记录 | 通过：两个脚本化模型的计划、分模型统计与恢复回归；协议违规与服务错误区分 |
| E07 最小模型接入 | 一个实际模型完成读题、查看/修改源码、公开测试、补丁冻结和独立评分；优先本地 Codex gpt-5.5，记录实际模型及接入限制 | 通过：9 月 14 日 gpt-5.5/high、5 次模型调用，Docker softmax resolved、verify 通过；后续重构通过脚本化客户端回归 |
| E08 内聚性与可用性 | 删除退役执行/网关/统计路径及其专用资产；测试夹具和文档指向活动入口；干净安装和相关回归可执行 | 通过：退役与重复流程删除、唯一评分来源、统一报告与工具校验；夹具归入 tests/fixtures、文档入口同步 |

本轮工程范围验收完成，当前为未正式发布的 `0.8.0.dev1`。9 月 14 日真实联调使用
`controlled-tools-1`；当前工具为 `controlled-tools-2`、循环为 `opbench-fixed-tools-3`。
原联调不能当作最新版真实多模型实验，正式实验前仍需逐服务联调。
详细命令、历史失败和接入限制在[验证报告](validation_report.md)维护；
[9 月 14 日结构化记录](validation_controlled_20260914.json)保留当时条件。测试数量不是完成条件；以关键行为是否得到
验证判断，避免固定文件、hash 或文档内容的无意义测试。
