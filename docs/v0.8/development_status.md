# v0.8 当前状态

更新于 2026-09-23。v0.8 工程范围的实现与本地验收已完成，当前软件包为
`0.8.0.dev1`，尚未正式发布。
主流程是固定模型循环、受控 MCP 工具、冻结补丁的独立评分和 `resolved_rate` 报告。
当前代码职责与阅读路径见[架构导读](../architecture.md)。
模块内部已收敛为独立评分文件与路径引用，运行记录按版本、用途和批次保存；
旧结果去向和新批次约定见[运行记录](../../runs/README.md)。
工程小题统一放在 `tests/fixtures/`，不计入评测数据；模型、运行与评分的关键边界
已补充代码注释。模型 API 和后续 Agent 框架接入的区别见[接入指南](agent_integration.md)。

实际测试、安装联调、Codex `gpt-5.5` 小任务及 CPU/CUDA 控制结果，统一记录在
[验证报告](validation_report.md)中。各记录保留当时的软件、工具和任务身份；
早期自主 Agent 结果不作为当前固定循环的新证据。验收目标见[工程验收](acceptance_matrix.md)，
实施经过见[执行计划](implementation_plan.md)，版本变化见 [CHANGELOG](../../CHANGELOG.md)。

最新完整回归为 9 月 22 日的 224 项测试（Docker 启用、无跳过），并完成三套测试
夹具的控制检查与仓库外安装验证。9 月 23 日仅补充注释、接入说明及文档一致性
修订，没有运行新的真实模型或完整 GPU 实验。真实 Codex 小任务属于 9 月 14 日
当时的协议；当前多模型编排有脚本化回归，尚无正式多提供商统一实验结果。

v0.9 更新分类数据和选题/准入流程，每类至少 10 条独立任务；v0.10 在固定 MCP
框架下开展多模型实验。框架对比和行为分析留到后续。旧 50 题的[静态审查](task_disposition.md)
及三份[迁移候选](../../datasets/v0.8_candidates/README.md)是后续数据建设的输入，未正式准入。
现有运行器支持多模型配置；正式实验前需固定任务、环境、工具、软件和预算，
逐服务做真实 API 小样本联调。接口不兼容时在模型客户端处理，不改变独立评分规则。
代码许可仍待作者与学校确认。

历次设计、实施和实验原文见[版本历史](../history/README.md)。它们记录当时的结论，
当前使用说明以[文档导航](../README.zh-CN.md)为准。
