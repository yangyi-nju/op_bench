## 旧路径与复核

v0.8 的两个旧入口 `runs/v0.8_rebuild_validation` 和 `runs/v0.8_controlled_validation` 通过本地 `.legacy-paths/` 链接到新批次，保留原始证据中的路径定位。该路径桥接仅用于已有归档，新实验使用新目录。

历史记录中声明的环境、源码位置和构建路径属于原实验条件。目录整理不证明旧基线可以复用，也不将旧实验升级为当前协议；需要重跑时另建批次。`verify` 和只读报告可用新路径检查已保存的相对证据。
